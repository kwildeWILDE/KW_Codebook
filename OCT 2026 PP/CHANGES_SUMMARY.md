## Implementation Details

### Outlier Detection Algorithm:
1. **Extract contour path** from the outer (outermost) contour line generated by `ax.contour()`
2. **Test point containment** using matplotlib's `contains_points()` method
3. **Identify outliers** as points NOT contained within the outer contour
4. **Filter by date** to only mark outliers occurring on May 7, 2026 and April 23, 2026

### Visual Indicators:
- **Green points (size=5)**: All valid data points in the regime
- **Red stars (size=150)**: Outliers on the target dates (May 7 & Apr 23, 2026)
- **Dark red edge**: 1.5pt border on highlighted stars for better visibility
- **Zorder=4**: Stars are drawn on top of all other elements for maximum visibility

### Date Filtering:

target_dates = [np.datetime64('2026-05-07'), np.datetime64('2026-04-23')]
